# MYCAR Android app — prototype 1.1.0

اپ اندرویدی فارسی برای مدیریت خودروهای شخصی در بازار ایران. پروژه با Kotlin و Android SDK ساخته شده و برای ساخت APK از GitHub Actions استفاده می‌کند.

## امکانات فعلی

- ورود/ثبت‌نام نمایشی با شماره موبایل ایران و OTP آزمایشی ثابت `12345`؛ پیامک واقعی ارسال نمی‌شود.
- بدون خودرو پیش‌فرض؛ کاربر باید خودش خودرو اضافه کند.
- فهرست دسته‌بندی‌شده از برندها و مدل‌های رایج بازار ایران، شامل ایران‌خودرو، سایپا، MVM، فونیکس، چری، بهمن، کرمان موتور، پارس‌خودرو و چند برند وارداتی.
- افزودن چند خودرو، انتخاب خودروی فعال و ذخیره سال ساخت، کیلومتر و نام/پلاک دلخواه.
- دانلود عکس خودرو از Wikimedia Commons هنگام دسترسی به اینترنت و ذخیره محلی در فضای داخلی برنامه برای استفاده‌های بعدی. عکس‌ها در صورت پاک‌کردن داده‌های برنامه ممکن است حذف شوند.
- برنامه سرویس پیشنهادی اولیه برای پژو ۲۰۷؛ نمایش برنامه عمومی و هشدار برای سایر خودروها تا وقتی داده دفترچه دقیق همان تیپ تأیید شود.
- ثبت سرویس انجام‌شده شامل تاریخ، کیلومتر، محل انجام، هزینه و توضیحات؛ ثبت هزینه مرتبط در گزارش هزینه‌ها.
- ثبت یادآوری سرویس، سوابق تعمیرات و هزینه‌ها به تفکیک خودرو.
- رابط فارسی راست‌چین و ذخیره‌سازی محلی.

## ساخت APK در GitHub

1. محتویات این پوشه را در ریشه یک repository جدید با نام دلخواه (مثلاً `MYCAR`) قرار دهید؛ خود پوشه پروژه را به‌صورت پوشه تو در تو در مخزن قرار ندهید.
2. فایل‌ها را به شاخه `main` یا `master` push کنید.
3. در GitHub به **Actions → Build MYCAR APK** بروید. Workflow به‌صورت خودکار اجرا می‌شود؛ می‌توانید آن را با **Run workflow** هم اجرا کنید.
4. پس از موفقیت، artifact با نام `mycar-debug-apk` را دانلود و از حالت فشرده خارج کنید. فایل خروجی `app-debug.apk` است.

## نکات مهم و محدودیت‌های نسخه آزمایشی

- OTP ثابت `12345` صرفاً برای تست است. این روش احراز هویت واقعی نیست و نباید برای انتشار عمومی استفاده شود؛ نسخه تجاری به بک‌اند، سرویس پیامک، محدودسازی درخواست و کنترل امنیتی نیاز دارد.
- داده‌ها در SharedPreferences همین دستگاه ذخیره می‌شوند؛ همگام‌سازی ابری و انتقال حساب بین دستگاه‌ها پیاده‌سازی نشده است.
- فهرست مدل‌ها نمونه‌ای گسترده از مدل‌های رایج است، نه کاتالوگ رسمی و جامع همه تیپ‌ها و سال‌های بازار ایران. در نسخه بعد می‌توان آن را به دیتاست قابل به‌روزرسانی تبدیل کرد.
- عکس‌ها از اینترنت دانلود می‌شوند و در ZIP به‌صورت باینری بسته‌بندی نشده‌اند؛ اولین نمایش هر عکس به اتصال اینترنت نیاز دارد. URLهای Wikimedia Commons در کد مشخص شده‌اند.
- برای پژو ۲۰۷، بازه عمومی ۱۰٬۰۰۰ کیلومتر یا یک سال برای سرویس دوره‌ای/روغن در منابع راهنمای سرویس ۲۰۷i با موتور TU5/TU5P ذکر شده است. تیپ، سال ساخت، شرایط کارکرد و الزامات گارانتی می‌توانند تفاوت ایجاد کنند. دفترچه راهنمای همراه همان خودرو و آخرین اعلام سازنده اولویت دارند.
- برای مدل‌های دیگر، برنامه نمایش داده‌شده فعلاً راهنمای احتیاطی است و نباید جایگزین دفترچه راهنمای رسمی همان تیپ شود.
- کامپایل و اجرای واقعی APK در محیط تولید این ZIP تأیید نشده است؛ GitHub Actions اولین مرحله build واقعی خواهد بود.
