# همراه خودرو (Hamrah Khodro)

نمونه اولیه اندرویدی برای مدیریت مالکیت خودرو، ساخته‌شده با Kotlin و Android SDK.

## امکانات نسخه 1.0.0
- داشبورد خودرو
- ثبت/ویرایش نام خودرو، سال ساخت و کیلومتر فعلی
- ثبت یادآوری سرویس با کیلومتر و/یا تاریخ
- ثبت تعمیرات و سرویس‌های انجام‌شده
- ثبت هزینه‌ها در دسته‌های مختلف
- نمایش جمع هزینه‌ها و سوابق اخیر
- حذف موارد ثبت‌شده
- ذخیره‌سازی محلی روی گوشی با SharedPreferences
- رابط فارسی و راست‌چین

## ساخت APK از GitHub
1. یک repository جدید در GitHub بساز.
2. فایل‌های این پروژه را در ریشه repository بارگذاری کن.
3. به تب **Actions** برو و workflow با نام **Build Hamrah Khodro APK** را اجرا کن یا یک commit جدید push کن.
4. پس از موفقیت workflow، پایین صفحه اجرای workflow بخش **Artifacts** را باز کن.
5. فایل `hamrah-khodro-debug-apk` را دانلود و از حالت فشرده خارج کن. فایل نصب `app-debug.apk` است.

## ساخت روی کامپیوتر
نیازمند JDK 17، Android SDK و Gradle 8.9 است. در ریشه پروژه اجرا کن:

```bash
gradle assembleDebug
```

APK در مسیر زیر قرار می‌گیرد:

`app/build/outputs/apk/debug/app-debug.apk`

## نکات نسخه آزمایشی
- اطلاعات فقط روی همان دستگاه ذخیره می‌شوند؛ حذف برنامه یا پاک‌کردن داده‌های آن ممکن است اطلاعات را حذف کند.
- در حال حاضر اعلان زمان‌بندی‌شده اندروید، همگام‌سازی ابری، ورود کاربر، پیوست فاکتور، خروجی PDF و پایگاه داده آنلاین پیاده‌سازی نشده‌اند.
- مقادیر خودرو و سرویس‌ها توسط کاربر وارد می‌شوند؛ این نسخه کاتالوگ رسمی سرویس سازندگان را ندارد.
- APK تولیدشده از این workflow، نسخه debug برای آزمایش است و برای انتشار رسمی به نسخه release و امضای امن نیاز دارد.
