# MYCAR Android app — prototype 1.4.0

اپ اندرویدی فارسی برای مدیریت خودروهای شخصی در بازار ایران. پروژه با Kotlin و Android SDK ساخته شده و برای ساخت APK از GitHub Actions استفاده می‌کند.

## امکانات نسخه 1.4.0

- ورود/ثبت‌نام آزمایشی با شماره موبایل ایران؛ ورودی ۱۱ رقم و شروع با `09` کنترل می‌شود.
- OTP ثابت آزمایشی `12345` با مهلت ۱۲۰ ثانیه و فعال شدن ارسال مجدد پس از پایان زمان؛ پیامک واقعی ارسال نمی‌شود.
- بدون خودروی پیش‌فرض؛ کاربر خودرو را خودش اضافه می‌کند.
- فهرست دسته‌بندی‌شده از برندها و مدل‌های رایج بازار ایران.
- داشبورد فارسی با موعدهای سرویس پیش‌رو، هزینه‌ها و دسترسی سریع.
- ثبت سرویس انجام‌شده شامل تاریخ، کیلومتر، محل انجام، هزینه و توضیحات.
- برنامه نگهداری داخلی برای چند گروه خودروی رایج، شامل پژو ۲۰۷ TU5/TU5P، تیبا، دنا/محصولات رایج ایران‌خودرو، شاهین و MVM X22.
- تصویرسازی گرافیکی اختصاصی خودرو با Canvas (نسخه فعلی عکس واقعی اینترنتی دانلود نمی‌کند تا وابستگی شبکه و کتابخانه اضافه نشود؛ لوگو اپ با گرافیک خودرو بهبود یافته).
- **جدید ۱.۴:** تعریف و یادآوری بیمه بدنه و بیمه شخص ثالث (مدت اعتبار یک‌ساله). تاریخ اتمام در فرم افزودن خودرو وارد می‌شود و در داشبورد یادآوری نمایش داده می‌شود.
- **جدید ۱.۴:** هر خودرو پروفایل مستقل دارد. مفهوم «خودروی فعال» حذف و به «پروفایل انتخاب‌شده» و جابجایی آسان بین پروفایل‌ها تبدیل شد.
- **جدید ۱.۴:** بهبود UI فرم‌های ورود داده (فیلدها با پس‌زمینه و فاصله بهتر).
- **جدید ۱.۴:** الهام از طراحی carmaintenance.app برای کارت‌ها و ساختار داشبورد.
- ذخیره‌سازی محلی روی گوشی.

## ساخت APK در GitHub

1. محتویات این پوشه را در ریشه یک repository جدید قرار دهید.
2. فایل‌ها را به شاخه `main` یا `master` push کنید.
3. در GitHub به **Actions → Build MYCAR APK** بروید؛ Workflow به‌صورت خودکار اجرا می‌شود و از **Run workflow** نیز قابل اجراست.
4. پس از موفقیت، artifact با نام `mycar-debug-apk` را دانلود و از حالت فشرده خارج کنید. فایل خروجی `app-debug.apk` است.

## نکات مهم

- OTP ثابت `12345` فقط برای تست است و احراز هویت امن محسوب نمی‌شود. انتشار عمومی به بک‌اند، سرویس پیامک، محدودسازی درخواست و کنترل‌های امنیتی نیاز دارد.
- داده‌ها در SharedPreferences همین دستگاه ذخیره می‌شوند؛ همگام‌سازی ابری پیاده‌سازی نشده است.
- فهرست خودروها شامل مدل‌های رایج است و کاتالوگ رسمی و کامل همه تیپ‌ها و سال‌های بازار ایران نیست.
- برای نمایش عکس واقعی خودرو از اینترنت، می‌توان در نسخه‌های بعدی با Coil/Glide + URLهای عمومی مدل‌ها پیاده‌سازی کرد (مجوز INTERNET اضافه شده).
- بازه‌ها برای استفاده عادی‌اند؛ ترافیک سنگین، سفرهای کوتاه، گرما و گردوغبار می‌توانند نیاز به سرویس زودتر ایجاد کنند.
